# Dataset

The released dataset will contain simulated radar–jammer interaction samples used in the FRAIL experiments.

Planned fields include:

- received jamming I/Q waveform / radar state;
- radar action;
- reward / detection-related performance feedback;
- jamming waveform type and parameter configuration for simulation bookkeeping;
- train/test split information.

The final dataset organization and representative subsets will be provided after publication.
